# Bauloo Styles

Client-seitige Fabric-Mod für Minecraft 1.21.11 mit drei Style-Bereichen,
alle über ModMenu konfigurierbar (Config: `config/bauloo-styles.json`):

- **Chat**: Uhrzeit, eigenes Präfix, Präfix-/Uhrzeit-/Textfarbe
- **HUD**: FPS- und Koordinaten-Panel mit Akzentfarbe, optionales Fadenkreuz (Punkt/Kreuz)
- **Menü**: Farb-Overlay auf Titelbildschirm (optional Pause-Menü), Akzentlinie, Versions-Label

Build: `./gradlew build` → `build/libs/bauloo-styles-1.6.0.jar`
